Suppliers

Bulk import suppliers

From a returned questionnaire: open the workbook, go to the Load sheet, select A3:J4 (the headings and the row under them), copy, and paste below. Several pros at once: paste the heading row once, then each pro's row under it.
The headings tell the import which column is which, so the order does not matter. Values containing commas are fine — Excel separates cells with tabs.
Typing by hand instead? One per line, comma-separated: name, email, phone, business name, ID number, area, services where services is carwash, laundry or both.
Imported pros are pre-approved, and a temporary password is generated for each. Banking details are not imported — the pro enters those in the app, where they are encrypted.
